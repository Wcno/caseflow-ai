# Decisión de interfaz

Se exploraron tres variantes en la rama `prototype/intake-ui`. Se escogió la variante A: captura a la izquierda y expediente a la derecha.

La separación mantiene visible el progreso mientras el colaborador entiende que el resultado sigue siendo revisable.

La decisión fue ampliada en septiembre de 2026: la captura continúa siendo un flujo enfocado, pero ahora convive con una bandeja de expedientes, biblioteca de procedimientos, seguimiento sintético del cliente y espacio de resolución. Estas vistas demuestran un workflow local; no representan un tablero conectado a la operación bancaria real.
